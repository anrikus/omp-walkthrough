# The Harness Layer — an evidence-based introduction to omp

A narrated, animated web presentation about coding-agent harnesses and [omp](https://omp.sh) (oh-my-pi), built from cited research. Facts are as of **2026-10-08**.

**Watch it:** https://anrikus.github.io/omp-walkthrough/

> Independent community explainer. Not affiliated with Stencil Labs or any vendor discussed.

## What's inside

14 standalone chapters (≈44.5 min of narration), a Feature Atlas, and a References page. Every on-screen claim has an evidence chip. The chip opens the claim, its evidence grade, and its sources.

## Run it

```sh
npm install
npm run dev        # http://localhost:5173
npm run build      # static site in dist/ (relative base, works from any subpath)
npm run preview
```

Browsers need one click (Start) before audio can play; after that, chapters auto-advance. Keys: Space play/pause, ←/→ ±5 s, M chapters, F fullscreen, C captions, R references, Esc close. Deep links work too: `#ch03`, `#ch03/3.2`, `#atlas`, `#references`.

## Deploy

Every push to `main` runs `.github/workflows/deploy-pages.yml`: `npm ci`, strict validation, build, and a GitHub Pages deployment of `dist/`. The narration audio and cues are committed, so CI never runs the TTS pipeline. Any static host works too: upload `dist/`.

## How it is made

| Stage | Where | Notes |
|---|---|---|
| Research | `research/01…12-*.md` | One cited dossier per topic, graded sources, conflicts and open questions recorded. `research/00-synthesis.md` summarizes. |
| Fact base | `research/claims.json`, `bibliography.json`, `citation-map.json` | Generated by `python3 research/tools/build_bibliography.py` |
| Script | `script/outline.md`, `narration/chNN-*.json` | Sentences with claim IDs, on-screen strings, storyboards |
| Fact-check | `script/factcheck/chNN.md` | Per-item verdicts and the primary sources opened |
| Narration | `tools/tts/` → `public/audio`, `public/captions`, `src/generated/cues` | Offline Kokoro-82M (q8, voice af_heart), sentence-exact cues |
| App | `src/` | Vite + TypeScript, DOM/SVG; the narration audio is the only clock, so every frame is a pure function of time |

### Regenerate data and narration

```sh
npm run data                      # rebuild src/generated/evidence.json from research + narration + atlas
npm run validate -- --strict      # schema, citations, cues, budgets, scene coverage
npm --prefix tools/tts ci
npm --prefix tools/tts run synth -- --check            # print lexicon-applied TTS text, no audio
npm --prefix tools/tts run synth -- --chapter ch03     # regenerate one chapter
npm --prefix tools/tts test
```

Pronunciation fixes go in `narration/lexicon.json`, which affects speech only; captions keep the real spelling. Output is deterministic for pinned inputs on the same machine and runtime; `narration/manifest.json` records provenance and hashes.

If `registry.npmjs.org` is unreachable, point npm at a mirror, e.g. `npm config set registry <mirror-url>`; the lockfiles resolve against `registry.npmjs.org`, which npm rewrites to the configured registry.

```
tools/tts/       offline narration pipeline
```
