## Safety and reproducibility

- Binary: `/opt/homebrew/bin/omp` resolving to `/opt/homebrew/Cellar/omp/18.8.6/bin/omp`; observed `--version` output: `omp/18.8.6`.
- Fixed PTYs: 120×36 and 160×45, `TERM=xterm-256color`, `COLORTERM=truecolor`, UTF-8 locale.
- Disposable root: `/tmp/omp-tui-reference-n8bbs6dg`. All capture sessions ran from its `project` directory with a clean environment allowlist, not the launching agent's credential-bearing environment. `HOME`, `PI_CONFIG_DIR`, `PI_CODING_AGENT_DIR`, all XDG roots, `TMPDIR`, and `--session-dir` pointed inside that root. `--no-title` and `PI_NO_TITLE=1` prevented automatic title generation. Config/session isolation is documented in [config-usage.md lines 60–86](https://github.com/can1357/oh-my-pi/blob/v18.8.6/docs/config-usage.md#L60-L86) and [CLI flags lines 69–97](https://github.com/can1357/oh-my-pi/blob/v18.8.6/docs/cli-reference.md#L69-L97).
- Every TUI/gallery/export capture child ran through `/usr/bin/sandbox-exec -p` with `(version 1) (allow default) (deny network*) (deny file-write* (subpath "/Users/anrikus")) (deny file-read* (subpath "/Users/anrikus/.omp"))`. The version/help probes used the same disposable environment. No provider was authenticated, no API key was supplied, no free-form prompt was submitted, and no real tool call was executed.
- First launch entered setup. Escape skipped each of five steps; those skips affect only the disposable profile. The local-model variant passed `--model apple/on-device` but submitted no inference request. The Anthropic provider category was only highlighted; its `Enter = log in` action was **never invoked**.
- History loading used `--resume <disposable JSONL>` with no positional message. [Read fixture](captures/history-fixture.jsonl) and [read+edit fixture](captures/history-edit-fixture.jsonl) use documented v3 header/entry shapes, camelCase `toolCall` content and `toolResult` roles. These records contain invented text/usage for safe rendering, not executed work. [Session format](https://github.com/can1357/oh-my-pi/blob/v18.8.6/docs/session.md#L63-L206)
- Gallery invocation: `omp gallery --tool <name> --state done --width <columns>`. The lifecycle example omits `--state`. Shipped state names/aliases are streaming/“streaming args”, progress/“in progress”, success/done, and error/failed. [Gallery source](https://github.com/can1357/oh-my-pi/blob/v18.8.6/packages/coding-agent/src/cli/gallery-cli.ts#L32-L55)
- PNG capture uses an embedded local monospace font, an xterm WebGL grid and a small right/bottom padding; `.txt` is the final xterm screen buffer. The cumulative raw `.ansi` PTY streams (including prior onboarding/overlays) were recorded locally but are not published in this repository (32 MB); the PNG and `.txt` grid are the reference. Final assets do not depend on `/tmp` font/renderer paths.

## Important interpretation limits

- **Startup, status line, slash palette, model selector, and rendered tool-call history are all captured as real PNGs.** For the strongest transcript proof, use [tool-history-edit-160x45.png](captures/tool-history-edit-160x45.png): it shows a resumed read row and a real production edit-diff component from the documented synthetic session.
- `read.toolResultPreview` defaults false. The resumed read history correctly hides its body, even after Ctrl+O. The gallery's full read body is a different composition path. Do not imply it is the default interactive experience. [Setting](https://github.com/can1357/oh-my-pi/blob/v18.8.6/packages/coding-agent/src/tools/settings.ts#L277-L280), [gate](https://github.com/can1357/oh-my-pi/blob/v18.8.6/packages/tui/src/chat/read-tool-group.ts#L1196-L1197)
- Real IDs present in the bundled catalog are not proof of credentials or external availability. No-auth startup says `no-model`; the local `apple/on-device` selection shows friendly footer name `Apple AFM 3 Core Advanced`. The 35-item selector count is this no-auth Apple-host capture, not a universal catalog total.
- Shipped gallery fixtures may contain old paths, synthetic TODO text, invented token/cost/duration numbers, or legacy edit argument shapes. Use them to reproduce rendering, not as proof of current tool semantics or actual performance.
- Native terminal integration/Glyph Protocol, alternative fonts, terminal background, macOS emoji fallback, and theme selection can change pixels. The underlying captured character grid remains available; do not claim pixel identity across all terminals.

## Before/after home-directory audit — explicit limitation

The requested globally unchanged `~/.omp` condition **cannot honestly be reported as met** in this live agent host. The snapshots contain 20,887 entries before and 21,367 after, with 619 metadata/listing differences. Other active sessions, databases, blobs, and caches changed concurrently; this walkthrough's host also writes its own tool logs. No attempt was made to revert, delete, or “repair” any of those changes.

Evidence: before/after listings of `~/.omp` (paths, mtimes, sizes) and their exact diff were recorded during capture. They are kept outside this repository because they list private local session and project paths. The real `agent/config.yml` had identical mtime/size/mode. `agent.db` changed, so these snapshots do **not** prove that global authentication-storage bytes remained unchanged. Metadata cannot attribute all concurrent writes to individual PIDs. The stronger child-process isolation evidence is the enforced deny-write/read/network sandbox plus the clean disposable environment in [manifest.json](captures/manifest.json); it does not make the entire live host tree immutable.

All observed capture PTY leaders were stopped/reaped; gallery/export commands exited. Interactive omp ignored the initial SIGTERM deadline and was terminated with SIGKILL after five seconds. No process command line containing the disposable root remained at the cleanup check. The capture browser tab was closed after screenshots. No project tests/builds or model inference were run.

The disposable root (fixture project, isolated profile/sessions, cloned source, and npm renderer dependencies) was removed after all source readers finished. The temporary `pyte==0.8.2` and `wcwidth==0.9.1` user-site installs were uninstalled. Final screenshots were produced with `@xterm/xterm==6.0.0` and `@xterm/addon-webgl==0.19.0`; no temporary raster HTML or font dependency remains in the final capture set. Only the intentional standalone session export is retained as HTML. [Cleanup and renderer manifest](captures/manifest.json)
