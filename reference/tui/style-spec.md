# omp 18.8.6 — terminal recreation style specification

Internal animation reference, captured 2026-10-08. **A capture is evidence of rendering, not evidence that a model or tool executed.** The binary reported `omp/18.8.6`; source inspection used tag `v18.8.6`, commit `f068751e2f1dbdbc195977776d47a26db8697495`. Capture conditions and every state are in [states.md](states.md).

## Authority and fidelity boundaries

1. Use the `.txt` beside each PNG as the final screen's character grid. The original cumulative PTY output (`.ansi`, including earlier frames) was recorded locally but is not published in this repository. The final PNGs use xterm.js with its WebGL renderer; the initial pyte/manual-HTML raster experiments were discarded. [Capture manifest](captures/manifest.json)
2. The TUI selects glyphs and ANSI styles, **not the terminal font**. These references deliberately use the locally installed **UbuntuSansMonoNerdFontMono-Regular.ttf**, embedded during rendering, at 20 CSS px; lineHeight=1, letterSpacing=0, deviceScaleFactor=1. xterm's WebGL cell grid is 11×24 px. A 120×36 terminal occupies 1320×864 px; a 160×45 terminal occupies 1760×1080 px. The PNG adds 16 px right and 8 px bottom padding so italic overhang is not cropped. This is a capture-font assumption, not an omp default. [Manifest](captures/manifest.json)
3. Unicode characters may be supplied by font fallback, notably emoji. The **Unicode preset remains selected**, despite the screenshot font containing Nerd Font glyphs. Do not replace the recorded Unicode characters with PUA/Nerd glyphs merely because the font supports them. A real Glyph Protocol handshake can upgrade the default Unicode preset; this PTY did not supply that handshake. [Theming docs](https://github.com/can1357/oh-my-pi/blob/v18.8.6/docs/theme.md#L84-L108), [settings capture](captures/settings-120x36.png)
4. The terminal's unstyled background/foreground were chosen as `#101010`/`#E5E5E5` for dark and `#FFFFFF`/`#202020` for light. These are **capture terminal defaults**, not Titanium token values. Titanium's `text` token is an empty string, meaning terminal-default foreground. [Titanium source](https://github.com/can1357/oh-my-pi/blob/v18.8.6/packages/tui/src/theme/defaults/titanium.json#L18-L83)
5. Shipped `omp gallery` uses genuine production component renderers with deterministic **synthetic** arguments, results, durations and costs. It is useful for component appearance, but does not prove the same composition in an interactive transcript. The read-tool distinction below is important. [Gallery source](https://github.com/can1357/oh-my-pi/blob/v18.8.6/packages/coding-agent/src/cli/gallery-cli.ts#L313-L378)

## Layout and status line

- **The composer is not a large input box by default.** The band layout places the status strip above a curved prompt beginning `╰─`; a thin context-reactive rule runs to the right. In the 120-column no-model capture the band is row 13 and the prompt row 14 (1-based); their vertical placement follows transcript height, not a permanent bottom dock. [Startup grid](captures/startup-120x36.txt), [plan grid](captures/plan-local-model-160x45.txt)
- The default segment order is left: `pi`, `vim`, `model`, `mode`, `collab`, `stream`, `path`, `git`, `pr`, `context_pct`, `cost`; right: `session_name`. Segments can be absent when inapplicable. Default path formatting abbreviates, strips a work prefix, and caps length at 40; git enables branch/staged/unstaged/untracked. [presets.ts 5–14](https://github.com/can1357/oh-my-pi/blob/v18.8.6/packages/tui/src/status-line/presets.ts#L5-L14)
- In the fixture, session title appears right-aligned above the band. With a known context window, the embedded rule can show a percent marker and total window instead of the no-model `7K/?` segment. The explicitly selected local model produced `86%` and `8.2K`; these are **this empty fixture's system-context measurements**, not model benchmark data or universal startup usage. [Read-history](captures/tool-history-read-160x45.txt), [local-model startup](captures/startup-local-model-160x45.txt)
- Fullscreen model/settings/agents selectors use one-cell rounded outer chrome, an interior divider, and a footer instruction row. The 120-column model selector's vertical split is at column 30 (1-based). The `/` palette is instead inline beneath the composer, with a selected chevron, command icon, padded name, description, and a right scrollbar; ten rows are visible in this capture. These are **observed fixture metrics**, not constants for every width. [Model grid](captures/model-selector-unconfigured-120x36.txt), [settings](captures/settings-120x36.txt), [slash palette](captures/slash-palette-120x36.txt)

### Model identity and counters

Do not assume a literal provider/model ID always appears in the footer. The selector uses provider-prefixed rows such as `apple/on-device`, and unconfigured-provider catalog rows show bare IDs such as `claude-opus-5-5`. ## Tool rendering: default transcript versus gallery

**Read preview is OFF by default.** Resuming the crafted session shows a compact `● Read src/greet.ts` row and no source body. Ctrl+O reports expansion enabled but does not bypass this preference. This is faithful behavior, not a broken fixture. The gate is `read.toolResultPreview=false`; `ReadToolGroupComponent` requires both that setting and content text to draw the preview. [Default setting](https://github.com/can1357/oh-my-pi/blob/v18.8.6/packages/coding-agent/src/tools/settings.ts#L277-L280), [preview gate](https://github.com/can1357/oh-my-pi/blob/v18.8.6/packages/tui/src/chat/read-tool-group.ts#L1196-L1197), [real replay](captures/tool-history-read-160x45.png), [Ctrl+O replay](captures/tool-history-read-expanded-160x45.png)

The gallery read frame is a **different production path**, `readToolRenderer.renderResult`, which draws a code cell. Its fixture provides `details.displayContent.text` and `startLine`, so displayed code has normal line numbers rather than the full model-facing `[path#HASH]`/`N:` envelope. Do not use that gallery body as the shipped-default chat view without explicitly showing preview enabled. [read.ts 463–643](https://github.com/can1357/oh-my-pi/blob/v18.8.6/packages/tui/src/tools/read.ts#L463-L643), [gallery fixture](https://github.com/can1357/oh-my-pi/blob/v18.8.6/packages/coding-agent/src/cli/gallery-fixtures/fs.ts#L124-L158), [read component capture](captures/gallery-read-done-120x36.png)
